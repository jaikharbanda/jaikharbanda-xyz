## How I work

Everything gets measured, logged and turned into a framework someone else could run. When a channel works once, I write the runbook. When it fails, I write down why and set kill criteria before trying again. Signals decide which accounts get attention; the calendar just executes.

The distinctive part is that the engine itself runs on AI. Claude Code and MCP drive my enrichment, campaign builds and CRM hygiene, with approval gates where a human should stay in the loop. Campaigns that used to take an afternoon get built in minutes, which means the scarce resource goes back to being judgement.

## Things I've built and stand behind

- A design partner qualification framework that scores actions, never compliments
- An outbound audit across 100+ campaigns that changed our channel strategy
- A re-engagement workflow that turned dead leads into booked calls, now a standing system
- A members' club talk circuit that works as top-of-funnel for enterprise deals
